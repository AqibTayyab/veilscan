## 2. Trademark Considerations

### 2.1 What Is a Trademark?

A trademark is a word, name, symbol, or combination that identifies the source of goods or services and distinguishes them from those of others. Registering a trademark gives you exclusive legal rights to use that name in your industry/category.

### 2.2 Do You Need to Register VeilScan as a Trademark?

**Short answer:** Not immediately, but you should be aware of your rights.

**Unregistered (Common Law) Trademark:**
You automatically acquire common law trademark rights the moment you start using "VeilScan" publicly in commerce. This gives you some protection in your geographic area without registration.

**Registered Trademark:**
Filing with a trademark office (USPTO for USA, EUIPO for EU, IPO for UK) gives you:
- Nationwide legal presumption of ownership
- Right to use the ® symbol
- Stronger legal basis to prevent others from using the name
- Ability to list on trademark registries (which deters copycats)
- Basis for international protection

### 2.3 Trademark Classes Relevant to VeilScan

Trademarks are filed under International Classes (Nice Classification):

| Class | Description | Relevance |
|-------|-------------|-----------|
| **Class 9** | Computer software, security software | ✅ Primary — the tool itself |
| **Class 42** | Software as a service, security testing services | ✅ If you offer services |
| **Class 41** | Education, training | Consider if you create courses |

**Primary class to file under: Class 9** — Computer software for network security auditing.

### 2.4 Trademark Search — Do This Before Launch

Before claiming trademark rights, verify no one else is using "VeilScan":

**Search these databases:**
1. **USPTO** (USA): https://www.uspto.gov/trademarks/search
   - Search: "VeilScan" in Class 9
   - Also search: "Veil Scan" (with space)

2. **EUIPO** (European Union): https://euipo.europa.eu/eSearch/
   - Same searches as above

3. **WIPO Global Brand Database** (International):
   https://branddb.wipo.int/

4. **Google Search:** `"VeilScan" software` — check for any existing tools or businesses

5. **PyPI:** https://pypi.org/search/?q=veilscan — check the package name

6. **GitHub:** https://github.com/search?q=veilscan — check for existing repos

**Based on available information:** "VeilScan" does not appear to be a registered trademark in the software/security space. However, always verify with current databases before launch.

### 2.5 Trademark Registration Process (USA — USPTO)

If you decide to register:

**Step 1 — TEAS Plus application** (~$250 per class)
File at: https://teas.uspto.gov

**Step 2 — Wait for examination** (typically 8-12 months)
USPTO examines for conflicts and legal requirements.

**Step 3 — Publication for opposition** (30 days)
Others can oppose if they believe it conflicts with their mark.

**Step 4 — Registration**
Receive Certificate of Registration. Valid 10 years, renewable.

**Step 5 — Maintenance**
File Declaration of Use between years 5-6. Renew at year 10.

**Note:** You can file "Intent to Use" before the product launches, which reserves the name.

### 2.6 Copyright vs Trademark — The Difference

| Protection | What it Covers | Automatic? | Cost |
|-----------|---------------|-----------|------|
| **Copyright** | The source code itself | ✅ Yes, automatically on creation | Free |
| **Trademark** | The name "VeilScan" | ⚠️ Common law only (no registration) | Free (unregistered) / ~$250 (registered) |
| **MIT License** | How others can use the code | ✅ Already applied | Free |

**Your code (VeilScan source) is already protected by copyright** the moment you wrote it. The MIT License grants others permission to use, modify, and distribute it — but the copyright remains yours.

## 4. Protecting the Brand

### 4.1 What To Watch For

After launch, monitor for:
- Other tools or software using the name "VeilScan"
- npm/pip/GitHub packages using the name
- Domain registrations with your name (typosquatting: vei1scan.com)
- Social media accounts impersonating VeilScan

**Tools for monitoring:**
- Google Alerts: set alert for "VeilScan" — free
- Namechk.com — check username availability across platforms
- PyPI RSS feed — monitor for similar package names

### 4.2 When Someone Misuses Your Name

If you find someone using "VeilScan" for a competing tool:

1. **First:** Contact them directly — ask them to rename
2. **Second:** File a DMCA takedown if they're using your code without credit
3. **Third:** If registered trademark is infringed — consult an IP attorney
4. **Fourth:** If on GitHub — report to GitHub via their trademark policy

### 4.3 How to Respond to Forks

Forks are allowed under MIT License. However:
- Forks cannot call themselves "VeilScan" if they're a different product
- Forks must include your copyright notice
- Forks cannot misrepresent themselves as the official VeilScan

## 5. Open Source Brand Guidelines

Since VeilScan is MIT licensed, here are guidelines for people who fork or build on it:

### What others CAN do:
- Fork VeilScan and modify it under MIT License
- Build tools that "use VeilScan" or "are powered by VeilScan"
- Reference VeilScan in documentation or blog posts
- Include VeilScan in security toolkits or bundles

### What others CANNOT do:
- Call their modified fork "VeilScan" without clarity that it's a fork
- Imply they are the official VeilScan project
- Remove your copyright notice from the code
- Use the VeilScan name to endorse their products without permission
